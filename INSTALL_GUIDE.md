# 📱 Cara Install Sikumbang di Perangkat Anda

Sikumbang dapat diinstall di smartphone, tablet, atau komputer Anda untuk akses yang lebih cepat!

## 🔷 Android (Chrome, Samsung Browser, Edge)

### Cara Install:
1. **Buka aplikasi browser**
   - Chrome, Samsung Internet, atau Microsoft Edge

2. **Buka Sikumbang**
   - Kunjungi https://domain.com/KP atau scan QR code

3. **Tunggu notifikasi install**
   - Button "Install App" akan muncul di bawah layar
   - Atau cek icon menu (⋮) → "Install app"

4. **Tap "Install App"**
   - Modal popup akan muncul

5. **Tap "Install" pada popup**
   - Tunggu proses selesai

6. **Selesai!**
   - Sikumbang akan ditambahkan ke home screen
   - Cek app drawer atau home screen untuk icon Sikumbang

---

## 🍎 iPhone / iPad (Safari)

### Cara Install:
1. **Buka Safari**
   - Aplikasi bawaan Apple

2. **Kunjungi Sikumbang**
   - Buka https://domain.com/KP

3. **Tap Share button**
   - Icon ⬆️ di bagian bawah layar

4. **Scroll dan tap "Add to Home Screen"**
   - Geser ke kanan jika tidak terlihat

5. **Beri nama (optional)**
   - Default: "Sikumbang"
   - Bisa diganti nama custom

6. **Tap "Add"**
   - Tunggu proses selesai

7. **Selesai!**
   - Icon Sikumbang akan muncul di home screen
   - Buka seperti aplikasi biasa

---

## 💻 Desktop (Windows, Mac, Linux)

### Chrome / Edge / Brave:
1. **Buka browser**
   - Chrome, Microsoft Edge, atau Brave

2. **Kunjungi Sikumbang**
   - Buka https://domain.com/KP

3. **Tunggu icon install**
   - Biasanya muncul di address bar (bujur sangkar + ⬇️)
   - Atau menu (⋮) → "Install app"

4. **Klik icon install**
   - Modal akan muncul

5. **Klik "Install"**
   - Pilih lokasi folder (optional)

6. **Selesai!**
   - Sikumbang akan muncul di:
     - Start Menu (Windows)
     - Applications (Mac/Linux)
     - Desktop (opsional)
   - Buka seperti aplikasi biasa

## 🔄 Memperbarui Sikumbang

Sikumbang akan **otomatis update** ketika:
- Pembuat membuat versi baru
- Update akan didownload di background
- Refresh halaman untuk gunakan versi baru

**Manual update:**
1. Buka aplikasi Sikumbang
2. Menu app (⋮) → Refresh / Update
3. Atau tutup app dan buka ulang

## ❓ FAQ

**Q: Apakah aman diinstall?**
A: Ya! PWA Sikumbang dikelola official dan aman digunakan.

**Q: Apakah perlu internet?**
A: Untuk pertama kali install perlu internet. Setelah itu bisa digunakan offline untuk fitur tertentu.

**Q: Berapa storage yang dibutuhkan?**
A: Hanya ~10-50MB untuk cache files. Jauh lebih ringan dari aplikasi native.

**Q: Bisakah diuninstall?**
A: Ya! Hapus icon dari home screen seperti aplikasi biasa.

**Q: Apakah bisa uninstall dari app manager?**
A: Ya! Di Android: Settings → Apps → Sikumbang → Uninstall

**Q: Datanya aman?**
A: Data tersimpan lokal di perangkat. Sama aman seperti browser.

## 📞 Bantuan

Jika ada masalah saat install:

1. **Cek koneksi internet** - Pastikan terhubung WiFi atau data
2. **Update browser** - Gunakan versi terbaru Chrome/Safari/Edge
3. **Clear browser cache** - Settings → Delete browsing data
4. **Coba ulang** - Reload halaman dan coba install lagi
5. **Hubungi admin** - Jika masalah tetap berlanjut
